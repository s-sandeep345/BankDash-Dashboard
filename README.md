# BankDash.Bank Dashboard

A responsive React banking dashboard inspired by the supplied Figma structure, with a completely different visual theme.

## Theme
Modern emerald / teal / warm-neutral palette instead of the original blue/purple theme.

## Pages
- Dashboard
- Transactions
- Accounts
- Investments
- Credit Cards
- Loans
- Services
- My Privileges
- Settings
- Transaction Detail
- Account Detail
- Investment Detail

## Features
- Responsive desktop / tablet / mobile layouts
- Collapsible desktop sidebar and mobile drawer
- Animated cards, charts, table rows and page transitions
- Search and transaction filters
- Transfer modal
- Add account modal
- Credit-card freeze toggle
- Loan progress/detail
- Investment performance chart
- Settings toggles
- Reusable components
- Recharts data visualizations
- Mock frontend data only

## Run
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```
